Where the list comes from

The original 21,953 blocks are the Patoshi set first identified by Sergio Demian Lerner from the nonce pattern in early blocks, as published by Jameson Lopp in 2022. The 134 additions were confirmed in October 2026 against chain data. Patoshi being Satoshi is a widely held hypothesis, not a proven fact.

How these addresses work

In 2009 the Bitcoin client paid block rewards in an older output format called P2PK, before 1… addresses were the norm. Each address here is the standard 1… address for that reward, which is what wallets and block explorers show. Spend status refers to the block reward itself.
